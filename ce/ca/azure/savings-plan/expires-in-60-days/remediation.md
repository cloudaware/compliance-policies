# Remediation

1. In the Azure portal, open **Cost Management + Billing** and select
   **Savings plans**.
2. Review the plan's eligible compute usage, utilization, scope, term, and
   hourly commitment with the workload owner and FinOps team.
3. Compare the expected demand and cost with pay-as-you-go pricing and the
   available Savings Plan options.
4. If continued coverage is justified, purchase a new Savings Plan with the
   approved scope, term, and hourly commitment. Azure Savings Plans are not
   renewed in place.
5. If replacement coverage is not justified, document the decision and update
   budgets and forecasts for the expected pay-as-you-go charges.
