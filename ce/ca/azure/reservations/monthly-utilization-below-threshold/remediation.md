# Remediation

Review the Reservation's monthly utilization in the Azure portal and compare
several periods before making a change. Confirm whether the shortfall is seasonal,
caused by a scope or SKU mismatch, or expected to be consumed by planned demand.

If low utilization is persistent:

1. Move the Reservation scope to subscriptions or resource groups with matching
   usage, where appropriate.
2. For virtual machine Reservations, review instance size flexibility and the
   workloads eligible for the benefit.
3. Evaluate an exchange or refund only if the Reservation is eligible under the
   current Azure terms and limits.
4. Reduce the quantity or change the SKU, region, or scope of future purchases and
   renewals.

Validate the effect on every covered workload with the workload owner and FinOps
team before making a change.
