# Remediation

## From Azure Portal

1. Go to `Microsoft Entra ID`.
2. Under `Manage`, click `Users`.
3. Click `Per-user MFA` from the top menu.
4. Click the box next to a user with `Status disabled`.
5. Click `Enable MFA`.
6. Click `Enable`.
7. Repeat steps 1-6 for each user requiring remediation.
