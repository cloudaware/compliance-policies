# Description

The Breeze Agent is a scheduled task that streams OS-level telemetry (users, services, mount points, and more) into the Cloudaware CMDB, enabling modules such as Intrusion Detection (IDS), Vulnerability Scanning, Patch Management, CIS Benchmarking, and Event Monitoring.

Ensure all instances have Breeze installed to maintain full visibility into OS-level telemetry and to enable these modules where required.
